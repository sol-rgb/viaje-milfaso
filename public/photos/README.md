# Fotos

Cada carpeta toma hasta 5 fotos, nombradas `01`, `02`, `03`, `04`, `05`
con extensión `.jpg`, `.jpeg`, `.png` o `.webp`.

    public/photos/mancora/01.jpg
    public/photos/mancora/02.jpg
    ...

Si falta una foto, la web dibuja sola un degradado con el color del viaje,
así que nunca se rompe. Apenas soltás el archivo con el nombre correcto,
aparece.

Carpetas: mancora, lima, cartagena, baru, miami, bahamas, cdmx, puerto-escondido
